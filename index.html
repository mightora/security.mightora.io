      Network transparency

      Model editing, comparison, review and export run locally. The online edition loads Mightora shared styling/components and an author image from external hosts. These requests are unrelated to uploaded model contents. The offline edition bundles these assets locally.

      To inspect requests, open browser Developer Tools (F12), select Network, enable Preserve log and reload. The on-screen description is not an independent network audit.
